# 🧮 Calculadora Simples em Python

Uma calculadora de terminal simples e interativa desenvolvida em Python. Este é o meu primeiro projeto no GitHub! 🚀

---

## 🚀 Funcionalidades

- **Operações Básicas:**
  - Adição (`+`)
  - Subtração (`-`)
  - Multiplicação (`*`)
  - Divisão (`/`)
- **Tratamento de Entradas:**
  - Aceita números decimais formatados com vírgula ou ponto (ex: `2,5` ou `2.5`).
  - Validação de erros para evitar que o programa feche em caso de digitação incorreta.
- **Segurança:**
  - Verificação para evitar divisão por zero.

---

## 🛠️ Como Executar

### Pré-requisitos

Certifica-te de que tens o [Python 3](https://www.python.org/) instalado no teu sistema.

### Passos para execução

1. **Clona o repositório:**
   ```bash
   git clone https://github.com/LucasLimadaSilva/calculadora-em-python.git
   ```

2. **Acede à pasta do projeto:**
   ```bash
   cd calculadora-em-python
   ```

3. **Executa o ficheiro:**
   ```bash
   python main.py
   ```
   *(Nota: Se o teu ficheiro tiver outro nome, substitui `main.py` pelo nome correto).*
